# pandapower_test_network

Тестовый репозиторий для работы с электрическими сетями и экспериментов с **pandapower**.

## Цель

Здесь можно хранить небольшие тестовые сети, примеры расчётов и эксперименты с моделированием энергосистем.

## Стек

- Python
- pandapower

## Статус

Тестовый проект — структура и содержимое будут развиваться по мере экспериментов.
